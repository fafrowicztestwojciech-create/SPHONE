# SPHONE (Early Access)

> **Note:** This application is currently under active development. Some features may be incomplete or subject to change in future updates.

SPHONE is a free, lightweight desktop application created by Soft Specifications.

---

### Important Information
If you click the **"Free Start"** button within the application, you will see the following popup message:
> *"There is no official window system yet"*

---

### Installation & Download
1. Go to the [Releases](https://github.com/fafrowicztestwojciech-create/SPHONE/releases) section of this repository.
2. Download the latest `SPHONE_Setup.exe` file.
3. Run the setup and follow the installation wizard.
